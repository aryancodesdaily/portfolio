# Portfolio AI Chatbot - Backend

Backend for an AI-powered chatbot integrated into my portfolio website.

The chatbot allows visitors to ask questions about my skills, projects, experience, education, and other portfolio-related information. The backend receives user messages, processes them using an LLM, and returns a relevant response.

## Features

- AI-powered conversational chatbot
- Portfolio-specific responses
- REST API for chat requests
- LLM integration
- Environment-based API key configuration
- CORS support for frontend integration
- Error handling for API requests

## Tech Stack

- Python
- FastAPI
- Groq API
- LLM
- Uvicorn
- python-dotenv
