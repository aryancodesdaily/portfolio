# Portfolio Website - Frontend

Frontend of my personal portfolio website, showcasing my skills, projects, education, and experience.

The website also includes an AI-powered chatbot that allows visitors to interact with my portfolio information and ask questions about my background, skills, and projects.

## Features

- Responsive portfolio website
- About, Skills, Projects, Education and Experience sections
- Interactive UI
- AI-powered portfolio chatbot
- Backend API integration
- Responsive design for different screen sizes

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite
